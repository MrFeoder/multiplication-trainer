# Тренажёр таблицы умножения

Статический сайт-тренажёр для заучивания таблицы умножения. Без сборки, без внешних
зависимостей — чистые HTML, CSS и JavaScript.

**Живой сайт:** https://mrfeoder.github.io/multiplication-trainer/

## Что умеет

- Два диапазона множителей: первый (A) «от… до…» и второй (B) «от… до…».
- Четыре вида заданий, включаются галочками (можно выбрать несколько):
  - прямой — `7 × 8 = ?`;
  - пропущенный множитель — `7 × ? = 56` и `? × 8 = 56`;
  - обратный — `56 = ? × ?` (верна любая пара, в том числе перевёрнутая);
  - деление — `56 ÷ 7 = ?` и `56 ÷ 8 = ?`.
- Два способа ответа: вписать число (для обратного — два числа) или выбрать из
  4 вариантов.
- Раунд из N вопросов, экран итогов, разбор ошибок, лучший результат.
- Профили оформления: «Школьник» (по умолчанию), «Взрослый», «Нейтральный».

Настройки и лучшие результаты сохраняются в `localStorage` браузера.

## Как открыть

Достаточно открыть `index.html` в браузере (в том числе по `file://`) или зайти на
живой сайт по адресу выше.

## Как прогнать тесты

Нужен Node.js (проверено на v24). Внешних пакетов не требуется:

```
node --test
```

Тесты лежат в `test/`: `logic.test.js` (чистая логика), `markup.test.js` (разметка и
порядок подключения), `ui.test.js` (интерфейс на минимальном DOM-стабе).

## Структура

```
index.html   разметка: настройки, тренировка, итоги
styles.css   оформление, темы профилей, адаптив
logic.js     чистые функции (пул вопросов, варианты, проверка, итоги)
app.js       экраны, события, localStorage
test/        автотесты (node --test)
```

`logic.js` — UMD-модуль: в браузере создаёт глобальный объект `MTM`, в Node отдаётся
через `module.exports`.

## Как опубликовать

GitHub Pages из ветки `main`, папка `/ (root)`. Файл `.nojekyll` отключает сборку
Jekyll, поэтому публикуется ровно то, что лежит в репозитории.
